# Examples

Run `python -m examples.simulator_demo` from the project root to exercise the
milestone 3 backend through `PowerSupplyInterface`. It starts two simulated
outputs, turns CH1 off while CH2 continues, then explicitly turns both off and
disconnects. It prints simulated readings and does not write experimental files.

No hardware experiment has been performed by this build. Simulator-generated
example CSVs will be added with the relevant protocol milestones and labelled
as simulated.
