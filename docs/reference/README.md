# Instrument reference documents

Active authoritative references for the confirmed Aim-TTi QPX600DP:

- `qpx600d_dp_instruction_manual_48511-1460_issue14.pdf`
- `qpx600_addendum_48511-1461_issue1.pdf`

The addendum is treated as the later correction wherever it qualifies or
conflicts with the main manual. See `../qpx600dp_commands.md` for hashes, printed
page citations, identified ambiguities and the code/documentation boundary.

`superseded/cpx400dp_manual_issue1.pdf` is retained only to preserve the truth of
the Milestone 1-4 history. It is not an authority for QPX600DP capabilities,
commands, protocol behaviour or future implementation.
